# AxoBoard self-hosted fonts

The font sources in this directory were retrieved from the Google Fonts
repository at commit `ec626514f79f831f1ab848a82114a0ce7e2d6372` and converted
to Latin-subset WOFF2 files with fontTools. The retained `OFL.txt` files contain
the SIL Open Font License for each family.

- DM Sans source: `ofl/dmsans/DMSans[opsz,wght].ttf`
- Fredoka source: `ofl/fredoka/Fredoka[wdth,wght].ttf`

The generated assets retain the variable weight axes used by AxoBoard:
DM Sans 400–700 and Fredoka 500–700.
