# Integration brand assets

AxoBoard uses recognizable provider product/company marks instead of initials or generic placeholders.

## Asset standard

- Preserve official colors and geometry; do not recolor provider marks to match AxoBoard.
- Place marks on a neutral white tile with an AxoBoard border.
- Keep assets local so dashboards do not depend on third-party CDNs.
- Add an entry to the registry below before a connector reaches production.
- Confirm the provider's current trademark and partner-program requirements before public marketing or marketplace use.
